# Agent Tool Execution State Streaming - Implementation Plan

## Executive Summary

This document outlines the implementation plan for adding agent tool execution state streaming to T3Chat, enabling real-time visibility into AI agent actions (tool calls, thinking states, etc.) similar to Abacus.ai, Anthropic Console, and LangSmith.

**Goal**: Surface intermediate agent actions (tool invocations, thinking states, execution progress) in the chat UI via Server-Sent Events (SSE), providing users with transparency into the agent's decision-making process.

**Key Benefits**:
- Enhanced user experience with real-time feedback
- Debugging and observability for agent behavior
- Transparency into AI decision-making
- Industry-standard feature parity with leading platforms

---

## High-Level Architecture

### Current State
- **Backend**: Rust (Axum) with SSE streaming for chat completions
- **Frontend**: React/TypeScript with streaming chat client
- **Database**: PostgreSQL with `tool_calls` table already present
- **Streaming**: SSE-based, sends `ChatResponseChunk` with `delta` and `done` fields

### Target State
- **Backend**: Replace SSE stream format with structured agent events (unified event-based streaming)
- **Frontend**: Parse and render agent events in the message timeline
- **Database**: Leverage existing `tool_calls` table, add real-time status updates
- **Streaming**: Unified event-based SSE stream using `AgentEvent` enum

### Design Principles
1. **Extensible**: Easy to add new event types in the future
2. **Performant**: Minimal overhead, efficient serialization
3. **Type-Safe**: Strong typing on both backend and frontend
4. **Observable**: All tool executions logged to database

```rust
/// Agent execution event streamed to frontend
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum AgentEvent {
    /// Agent is thinking/planning (e.g., "Analyzing user request...")
    Thinking {
        message: String,
        #[serde(skip_serializing_if = "Option::is_none")]
        metadata: Option<serde_json::Value>,
    },
    
    /// Tool execution started
    ToolStart {
        tool_call_id: String,
        tool_name: String,
        tool_type: String, // "function", "web_search", "code_interpreter", etc.
        arguments: serde_json::Value,
        #[serde(skip_serializing_if = "Option::is_none")]
        metadata: Option<serde_json::Value>,
    },
    
    /// Tool execution progress/output (streamed incrementally)
    ToolOutput {
        tool_call_id: String,
        tool_name: String,
        output: serde_json::Value, // Can be partial or complete
        #[serde(skip_serializing_if = "Option::is_none")]
        is_partial: Option<bool>,
    },
    
    /// Tool execution completed
    ToolEnd {
        tool_call_id: String,
        tool_name: String,
        status: String, // "completed", "failed"
        #[serde(skip_serializing_if = "Option::is_none")]
        error: Option<String>,
        #[serde(skip_serializing_if = "Option::is_none")]
        result: Option<serde_json::Value>,
    },
    
    /// Text content delta (existing behavior)
    TextDelta {
        delta: String,
    },
    
    /// Final message completion
    MessageComplete {
        content: String,
        finish_reason: Option<String>,
        usage: Option<TokenUsage>,
    },
    
    /// Error event
    Error {
        message: String,
        #[serde(skip_serializing_if = "Option::is_none")]
        code: Option<String>,
    },
}
```

**Rationale**: 
- Tagged enum with `serde(tag = "type")` for efficient JSON serialization
- Matches OpenAI-style streaming event patterns
- Supports incremental tool output (useful for long-running tools)
- Unified event-based streaming format

```rust
pub async fn stream_chat(
    user: AuthenticatedUser,
    state: State<AppState>,
    Json(payload): Json<ChatRequest>,
) -> Result<Sse<impl Stream<Item = Result<Event, Infallible>>>, Response> {
    // ... existing setup ...
    
    // Get available tools (if agent is specified)
    let available_tools = if let Some(agent_id) = payload.agent_id {
        state.tool_executor.get_available_tools(Some(agent_id)).await
    } else {
        vec![] // Or default system tools
    };
    
    // Stream with tool support
    let event_stream = if !available_tools.is_empty() {
        ai_provider.stream_chat_with_tools(ai_request, available_tools).await?
    } else {
        // Regular streaming without tools, wrap text deltas in AgentEvent::TextDelta
        ai_provider.stream_chat(ai_request).await?
            .map(|chunk| {
                chunk.map(|c| AgentEvent::TextDelta { delta: c.delta })
            })
    };
    
    // Convert to SSE
    let sse_stream = event_stream
        .map(|event_result| {
            let event = event_result.unwrap_or_else(|e| {
                AgentEvent::Error { message: e.to_string(), code: None }
            });
            let json = serde_json::to_string(&event).unwrap();
            Ok(Event::default().data(json))
        });
    
    Ok(Sse::new(sse_stream).keep_alive(KeepAlive::default()))
}
```

### Phase 2: Streaming Client Updates

#### 2.1 Extend T3ChatClient

**File**: `web/src/lib/t3-chat-client.ts`

Modify `streamChat` to parse agent events:

```typescript
async *streamChat(data: ChatRequest): AsyncGenerator<AgentEvent, void, unknown> {
    const response = await this.stream("/chat/stream", { ...data, stream: true });
    
    if (!response.body) {
        throw new Error("Response body is null");
    }
    
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let lineBuffer = "";
    
    try {
        while (true) {
            const { done, value } = await reader.read();
            
            if (done) {
                if (lineBuffer.trim()) {
                    const event = this.parseSSEEvent(lineBuffer);
                    if (event) yield event;
                }
                break;
            }
            
            const chunk = decoder.decode(value, { stream: true });
            lineBuffer += chunk;
            
            const lines = lineBuffer.split("\n");
            lineBuffer = lines.pop() || "";
            
            for (const line of lines) {
                if (!line.trim()) continue;
                
                if (line.startsWith("data: ")) {
                    const event = this.parseSSEEvent(line);
                    if (event === null) return; // End marker
                    if (event !== undefined) {
                        yield event;
                    }
                }
            }
        }
    } finally {
        reader.releaseLock();
    }
}

private parseSSEEvent(line: string): AgentEvent | undefined | null {
    if (!line.startsWith("data: ")) return undefined;
    
    const data = line.slice(6).trim();
    
    // Check for end marker
    if (data === T3ChatClient.STREAM_END_MARKER) {
        return null;
    }
    
    try {
        const parsed = JSON.parse(data);
        
        // Validate it's an agent event with required type field
        if (parsed.type && Object.values(AGENT_EVENT_TYPES).includes(parsed.type)) {
            return parsed as AgentEvent;
        }
        
        return undefined;
    } catch {
        return undefined;
    }
}
```

### Phase 3: State Management

#### 3.1 Agent Event State Hook

**File**: `web/src/hooks/useAgentEvents.ts` (new)

```typescript
import { useState, useCallback } from "react";
import type { AgentEvent } from "@/types/agent-events";

export interface ToolExecutionState {
    tool_call_id: string;
    tool_name: string;
    tool_type: string;
    status: "running" | "completed" | "failed";
    arguments?: Record<string, unknown>;
    output?: unknown;
    error?: string;
    startedAt: Date;
    completedAt?: Date;
}

export function useAgentEvents() {
    const [thinkingMessage, setThinkingMessage] = useState<string | null>(null);
    const [toolExecutions, setToolExecutions] = useState<Map<string, ToolExecutionState>>(new Map());
    const [textContent, setTextContent] = useState<string>("");
    
    const handleEvent = useCallback((event: AgentEvent) => {
        switch (event.type) {
            case "thinking":
                setThinkingMessage(event.message);
                break;
                
            case "tool_start":
                setToolExecutions(prev => {
                    const next = new Map(prev);
                    next.set(event.tool_call_id, {
                        tool_call_id: event.tool_call_id,
                        tool_name: event.tool_name,
                        tool_type: event.tool_type,
                        status: "running",
                        arguments: event.arguments,
                        startedAt: new Date(),
                    });
                    return next;
                });
                break;
                
            case "tool_output":
                setToolExecutions(prev => {
                    const next = new Map(prev);
                    const existing = next.get(event.tool_call_id);
                    if (existing) {
                        next.set(event.tool_call_id, {
                            ...existing,
                            output: event.is_partial 
                                ? (existing.output ? `${existing.output}${event.output}` : event.output)
                                : event.output,
                        });
                    }
                    return next;
                });
                break;
                
            case "tool_end":
                setToolExecutions(prev => {
                    const next = new Map(prev);
                    const existing = next.get(event.tool_call_id);
                    if (existing) {
                        next.set(event.tool_call_id, {
                            ...existing,
                            status: event.status,
                            error: event.error,
                            output: event.result ?? existing.output,
                            completedAt: new Date(),
                        });
                    }
                    return next;
                });
                break;
                
            case "text_delta":
                setTextContent(prev => prev + event.delta);
                break;
                
            case "message_complete":
                setTextContent(event.content);
                setThinkingMessage(null);
                break;
                
            case "error":
                // Handle error
                break;
        }
    }, []);
    
    const reset = useCallback(() => {
        setThinkingMessage(null);
        setToolExecutions(new Map());
        setTextContent("");
    }, []);
    
    return {
        thinkingMessage,
        toolExecutions: Array.from(toolExecutions.values()),
        textContent,
        handleEvent,
        reset,
    };
}
```

```typescript
import { useAgentEvents } from "./useAgentEvents";

export function useStreamingChat() {
    const [streaming, setStreaming] = useState(false);
    const [error, setError] = useState<Error | null>(null);
    const agentEvents = useAgentEvents();
    
    const sendMessage = useCallback(async (
        request: ChatRequest, 
        onChunk: (chunk: string) => void,
        onEvent?: (event: AgentEvent) => void,
        onComplete: () => void
    ) => {
        try {
            setStreaming(true);
            setError(null);
            agentEvents.reset();
            
            for await (const event of t3ChatClient.streamChat(request)) {
                // Handle agent event
                agentEvents.handleEvent(event);
                onEvent?.(event);
                
                // Extract text content for display
                if (event.type === "text_delta") {
                    onChunk(event.delta);
                } else if (event.type === "message_complete") {
                    onChunk(event.content);
                }
            }
            
            onComplete();
        } catch (err) {
            // ... error handling
        } finally {
            setStreaming(false);
        }
    }, [agentEvents]);
    
    return { 
        sendMessage, 
        streaming, 
        error,
        agentEvents,
    };
}
```

2. **Tool Execution**:

3. **Memory Management**:
   - Stream large tool outputs incrementally
